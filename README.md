## Como abrir no Windows

1. Entre em **Baixar para Windows** e abra a seção **Assets** da versão mais recente.
2. Baixe o arquivo que termina em **windows-x64-portable.zip**.
3. Extraia o ZIP inteiro e abra **lumi_play.exe** na pasta extraída.

Para atualizar, feche o Lumi Play, baixe a versão mais recente e extraia em uma nova pasta. Suas playlists e preferências ficam no perfil do Windows.
